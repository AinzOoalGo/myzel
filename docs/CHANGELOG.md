# Changelog

## Entstehung (Phasenplan, jede Phase vom Chef freigegeben)

1. **Konzept & Game-Design-Dokument** (27.10.2026) – vier Ideen vorgeschlagen, Chef wählte „Myzel“. Marktanalyse Play Store: Idle-Markt groß, aber von großen Studios dominiert; Chancen durch faire Monetarisierung, Risiko „Unsichtbarkeit“.
2. **Graubox-Prototyp (0.2)** – Spielkern, Tests, Balancing-Simulation.
3. **Netz-Grafik (0.3)** – leuchtendes Netz, Knoten-Grafiken, Kamera, Feedback.
4. **Inhalte & Balancing (0.4–0.5)** – Sporenflug, Genom, Ereignisse, Erfolge; Zone 2 mit Konkurrenzpilzen und Jahreszeiten.
5. **Polish (0.6)** – Ton, Sicherungskopie, Barrierefreiheit, Leistung, Gerätetests.
6. **Release (1.0)** – Web-App auf GitHub Pages.
